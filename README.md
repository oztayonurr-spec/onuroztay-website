# Onur Öztay — Kişisel Web Sitesi V3

Bu sürüm gerçek CV ve sanatsal portfolyo verileriyle hazırlanmıştır.

## Sayfalar
- index.html — Ana sayfa
- about.html — Biyografi / eğitim / çalışma alanları
- theatre.html — Oyunculuk, dramaturji, yönetmenlik, sinema-TV
- projects.html — Yaratıcı proje arşivi
- project.html — Proje detayları (query string ile)
- academic.html — Akademik profil, kitap bölümü, bildiri
- press.html — Dış kaynaklar / basında
- contact.html — E-posta ve sosyal medya

## Gizlilik kararı
CV'deki telefon, doğum tarihi ve açık kişisel bilgiler kamuya açık siteye eklenmedi.
Raw CV PDF'leri de bu nedenle site paketine konulmadı.

## Yayına almadan önce
1. Alan adı kesinleşince canonical URL, sitemap ve OpenGraph URL/absolute image alanları eklenmeli.
2. Gerçek X:Limbo / Hezarfen renderları sağlanırsa soyut proje görselleri onların yerine konulmalı.
3. İngilizce sürüm ayrı ve eksiksiz hazırlanmalı; bu sürümde göstermelik dil düğmesi yoktur.
